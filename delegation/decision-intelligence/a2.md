4. A provider-independent metric function/harness that consumes expected labels and predictions (or a provider callback) and reports classification accuracy, per-label counts, and a confusion matrix when practical. Config default/backward-compatibility evidence:

- `decision` is an optional key on the existing `.strict()` client config, so an existing config parses **unchanged** and the parsed object has no `decision` property at all — asserted as `expect('decision' in result.data).toBe(false)`.
- Both backward-compatibility fixtures parse without modification and with no `decision` key: the reference tenant (key for key, `isReferenceImplementation`, `support`, and its knowledge/integration arrays present) and the configurator-style config (`tryEmitClientConfig`'s shape). Because omission is indistinguishable from `off`, missing config behaves exactly like Foundation V1.1/off.
- Rejections are named, not vague: unknown mode → `decision.mode: Invalid option: expected one of "off"|"shadow"|"assist"`; `mode: 'shadow'` with no provider → `a provider is required unless mode is "off"`; provider must be a kebab-case slug; unknown task id (`tone_classification`) is named in its own issue; `minConfidence` outside 0–1 or non-numeric is rejected; an unknown key under `decision.tasks` is rejected by `.strict()`.
- Valid config round-trips: `Object.keys(result.data.decision)` is exactly `['mode', 'tasks']`, and all three modes parse (`off` without a provider, `shadow` and `assist` with one).
- No pricing field was added and Presence/Capability were not touched. The configurator emitter needs **no** change — it emits no `decision` key, which is already the default.

Corpus and metrics:

- Corpus: **51 cases** — 22 English, 17 Indonesian, 12 mixed Indonesian-English (`CORPUS_LANGUAGE_COUNTS` is computed from the cases, so the report cannot drift from the data). All six Foundation utterances appear verbatim, and the test asserts them by string rather than by id, so a paraphrase keeping the id would fail.
- Coverage intended by the brief: ambiguous reference (availability with a missing window, `clarification: clarify`), recommendation, comparison, explicit handoff, unsupported factual claim (`evidence_sufficiency: insufficient`), price-plus-availability in one utterance, support, and purchase cases. 25 cases require a live-system answer (`structured_truth`), 26 are published knowledge (`retrieval`).
- Every case carries `intent_classification` and `knowledge_routing`; the other three tasks are optional per case, so a case only speaks to the decision it is about. Each case carries a `why` line, so a disagreement is debatable rather than asserted.
- Metrics (`scorePredictions`, `predictByCase`, `evaluate`): overall and per-task accuracy, correct/incorrect/unanswered counts, per-label `predictedCounts`, a full confusion matrix in vocabulary order, and `invalidAnswers` for a prediction outside its task's vocabulary (never scored as correct, so a provider cannot earn accuracy by inventing labels). Out-of-vocabulary predictions still appear in the confusion row, so the miss is not hidden. An unanswered question counts against accuracy but is not recorded as wrong.
- Critical failures: `structured_truth → retrieval` on `knowledge_routing`, counted and listed separately from accuracy (PRD §17). Silence is not counted as a downgrade — the harness cannot see what the pipeline did with it. `criticalCapacity` reports how many cases could have exposed one: **25** for this corpus, so a zero count means something.
- Network-free by construction: the package imports nothing from `@archava/*`, opens no connection, and reads no environment variable. It duplicates the five task ids locally so it is usable before a1's package exists. Nothing here was produced by a live provider — the only numbers reported above are test and corpus facts, and no Jev evaluation is claimed.
- `formatReport` prints the human-readable CI line: `cases: 51`, `critical failures: 25 of 25 at risk`, one line per task. A task no case asked is omitted rather than printed as a misleading zero.
