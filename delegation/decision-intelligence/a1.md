# a1 — provider-neutral Decision Layer

## Assignment

Own only `packages/decision/**` and the Result section of this file. Build a new vendor-independent package around the frozen `DecisionProvider` port in `@archava/adapters`. Do not edit that port or any other agent's paths. Make the package usable by a later assistant integration without importing Jev types or libraries.

Deliver:

1. Public, typed task catalogue for `intent_classification`, `knowledge_routing`, `clarification`, `handoff_recommendation`, and `evidence_sufficiency`. Keep bounded answer sets and explicit baseline/fallback semantics. Design for future ranked/scored options without enabling future tasks.
2. A deterministic `RuleDecisionProvider` satisfying the existing `DecisionProvider` contract. It should work offline, including English, Indonesian, and mixed language inputs relevant to the reference tenant. It is the CI/eval baseline; do not pretend it is a live model.
3. A `DecisionOrchestrator` with `off`, `shadow`, and `assist`. `off` must avoid a provider call; `shadow` may call the provider but must return the deterministic baseline as effective; `assist` may apply only a configured task whose response is valid and meets that task's own confidence policy. Provider failure, timeout, refusal, malformed output, and low confidence fall back to the baseline. No global magic threshold.
4. Runtime validation of question/result shape: duplicate or unknown IDs, missing/extra decisions, wrong kinds, out-of-set choices, non-finite/out-of-range score or confidence, and inconsistent provider identity must fail closed. A TypeScript type alone is insufficient at the network boundary.
5. Metadata-first traces/events for evaluated, fallback, low confidence, and provider failure, including task, provider, mode, confidence, effective/candidate result, disagreement, whether runtime changed, and latency where practical. Never log full utterances, evidence, secrets, or cross-tenant mutable state.
6. Focused tests for all three modes, safe fallback, per-task thresholds, provider interchangeability using mock providers, and structured-truth precedence as a task policy. Keep the package network free.

Use the current adapter port as an input boundary. If its shape blocks a safe behavior, document the exact requested change below; do not edit the frozen file while a3 is using it. A `DecisionOrchestrator` API that accepts the deterministic baseline explicitly is preferred, so failures can preserve Foundation behavior. Export a clear small API from `packages/decision/src/index.ts` and document it in your result for lead integration.
