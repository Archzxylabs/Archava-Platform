Page Studio

This is the slice from §24: a page the SDK observes, and a chat shell that answers from what the tenant has published. Ask it about breakfast, wifi, check-in, or the pool — anything else is a decline, which is the honest answer.

Ask it to compare two of the resources below and the request travels the whole path — brain, gate, validation, executor — and the page changes. Ask for a payment and it is denied, which is the honest answer at this tier.

Add ?inspect=1 to the URL to see the §16 inspector beside the transcript, and window.archava in the console for what the pipeline decided.

Consent for page_context is granted by this page, so a turn can run. A page that granted nothing would still load — the SDK would record the notice saying why there is nothing to answer.
